# Full-Stack Integration & End-to-End Testing Matrix

## Testing Layers
1. **Unit Tests (JUnit 5, PyTest, Jest)**: Isolated domain logic testing with > 85% code coverage.
2. **Contract Tests (Pact)**: Consumer-driven contracts verifying cross-service gRPC schemas.
3. **End-to-End Tests (Playwright)**: Automated student journey verification (login, enrollment, quiz submission, grading feedback).
